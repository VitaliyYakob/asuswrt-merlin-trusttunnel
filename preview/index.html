Пауза сохраняет блокировку. Отключение возвращает выбранные сети к обычной маршрутизации Merlin.

1. Подключение к серверу

Локальная подготовка

Введите параметры вручную или вставьте ссылку TrustTunnel. Пароль остаётся в памяти этой страницы до экспорта; автоматического сохранения нет.

Поддерживается официальный формат TrustTunnel v1. Неподдерживаемые параметры будут показаны как ошибка. Ссылка содержит учётные данные.

Должно совпадать с сертификатом сервера.
IPv4 или hostname:port, по одному в строке.
Включайте в соответствии с настройками подключения.
Сертификат, DNS и дополнительные параметры
По одному адресу в строке.

Проверка TLS всегда включена. Для доверенного публичного сертификата поле можно оставить пустым.

Как применить подключение на роутере

В этой alpha конфигурация переносится по SSH. Штатное общее хранилище Merlin не используется для пароля.

  1. Скачайте trusttunnel-endpoint.json, ограничьте доступ к нему на компьютере и перенесите по SCP/SFTP в /tmp/ роутера.
  2. Отключите аддон перед изменением подключения. В SSH выполните:
chmod 600 /tmp/trusttunnel-endpoint.json
/jffs/addons/trusttunnel/trusttunnel.sh import-endpoint /tmp/trusttunnel-endpoint.json
# После успешного импорта:
rm /tmp/trusttunnel-endpoint.json

Скачанный файл содержит пароль. После импорта удалите свою временную копию из загрузок. Экспорт сам по себе не меняет настройки роутера.

2. Сети через VPN

0 сетей

Выберите основную и гостевые сети. В каждой строке укажите реальный bridge и IPv4-подсети либо отдельные адреса /32. Неотмеченные сети сохраняют обычную маршрутизацию Merlin.

br0–br3 — примеры имён, их нужно проверить на роутере. Поддерживается до 16 сетей и 32 записей подсетей суммарно.

Изменения доступны при отключённом аддоне. После сохранения проверьте результат операции. Переключение работающей политики без отключения пока не поддерживается.
