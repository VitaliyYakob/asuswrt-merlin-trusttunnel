# Предварительный релиз v0.3.1-alpha.19

Проект разработан совместно с **OpenAI Codex**. Панель клиента TrustTunnel доступна в разделе **VPN → TrustTunnel** ASUSWRT-Merlin.

## Что изменилось с alpha.18

- Кнопка **«Проверить обновления»** больше не сообщает об истёкшей сессии, если Merlin принял запрос и поиск завершился. Панель отрабатывает явный отказ в доступе или переход на страницу входа отдельно.
- После потери ответа кнопка **«Проверить результат»** находит исходную операцию по её идентификатору и типу. Для проверки достаточно прочитать статус уже отправленной команды.
- Если сохранение настроек подтвердилось после проверки результата, панель сбрасывает черновик и отображает сохранённое состояние.

## Установка и обновление

В выпуск входят IPK для Entware `aarch64-3.10`, архивы исходников ZIP и TAR.GZ, `SHA256SUMS`, манифест и подписанное свидетельство происхождения. При первой установке аддон скачивает официальный CLI и проверяет его подпись и контрольные суммы. При обновлении аддона сохраняется установленный CLI с корректным хешем.

Перед обновлением завершите пробное применение настроек и отключите VPN в панели. Установите IPK или выполните команду установки по ссылке. После установки проверьте настройки и нажмите **«Подключить»**. [Установка по ссылке](https://github.com/VitaliyYakob/asuswrt-merlin-trusttunnel#установка-по-ссылке) · [Установка IPK и зависимости](https://github.com/VitaliyYakob/asuswrt-merlin-trusttunnel/blob/main/docs/INSTALL.md)

## Проверки и ограничения

На ASUS RT-AX86U с Merlin 3004.388.12_2 проверили обновление alpha.18 → alpha.19 из IPK и кнопку «Проверить обновления» в панели по HTTPS. Одно нажатие успешно нашло CLI v1.1.12. Во время проверки продолжал работать установленный CLI 1.1.7. Настройки подключения, гостевой сети и LAN4 сохранились.

После обновления прошивки до Merlin 3004.388.13_0 подтвердили автозапуск аддона и двусторонний VPN-трафик гостевой сети. На LAN4 проверили выбор маршрута в туннель. Проверка трафика с устройства на порту на этой прошивке ещё предстоит. [Отчёт о проверках](https://github.com/VitaliyYakob/asuswrt-merlin-trusttunnel/blob/main/docs/TEST-REPORT.md)

Тестирование выполнялось на **ASUS RT-AX86U** с прошивками **3004.388.12_2** и **3004.388.13_0**. Минимальная поддерживаемая прошивка для установки — **3004.388.12**.
