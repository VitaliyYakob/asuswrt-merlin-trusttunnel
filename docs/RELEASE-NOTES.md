# Предварительный релиз 0.3.1-alpha.13

Разработано совместно с Codex. Экспериментальный клиент TrustTunnel с нативной панелью ASUSWRT-Merlin.

- Исправлены конфликты вкладок и ложное изменение подключения от показа пароля.
- Карточка сохранённого профиля и отдельное изменение транспорта/MTU/Anti-DPI без повторного ввода пароля и DNS.
- Явные режимы маршрутизации, отдельные SSID, список исключений, подтверждение URL → домен, понятное ожидание операции и проверка потерянного ответа.
- Установка с предварительной подготовкой файлов и возвратом при ошибке, ограниченное время чтения NVRAM, монотонные таймеры, журнал с ограничением размера и показатели процесса.
- Пробное обновление CLI на пять минут, пользовательское подтверждение, возврат предыдущего клиента, явное понижение версии и сохранение защитных правил.
- Манифест файлов и процесс подписания свидетельства происхождения через GitHub/Sigstore после полного CI точного коммита.

Версия подготовлена локально: 279 Python tests, JavaScript, ShellCheck и браузерные сценарии пройдены. Результаты и ограничения — в docs/TEST-REPORT.md. Установка alpha.13 на роутер, её аппаратные испытания и удалённая сборка пока не выполнялись; на действующем AX86U остаётся alpha.12/CLI 1.1.7. Минимум поставки Merlin 3004.388.12; фактически ранее тестировался RT-AX86U/3004.388.12_2. Пакет содержит исходники, официальный CLI скачивается и проверяется отдельно.
