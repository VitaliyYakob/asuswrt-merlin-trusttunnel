# Предварительный релиз 0.3.1-alpha.10

Экспериментальный нативный клиентский аддон TrustTunnel для ASUSWRT-Merlin, разработанный совместно с Codex.

- Русский README, демонстрационные снимки без рабочего сервера/сетей автора, зависимости, установка и удаление.
- IPK `aarch64-3.10`, установщик по ссылке с закреплённым SHA-256 IPK. Первоначальный официальный CLI не включён в пакет: скачивается отдельно и проверяется по хешам/GPG-подписи.
- Установщик не запускает VPN, отклоняет активную/незавершённую политику и сохраняет ранее обновлённый собственный CLI.
- Ручные stable/nightly обновления CLI, даты установки/проверки, отдельные SSID/подтверждённые списки устройств и исправление загрузки CSS из alpha.7–alpha.9.

Аппаратные проверки runtime выполнены на ASUS RT-AX86U / Merlin 3004.388.12_2 / kernel 4.1.52: гостевой VPN, смена IP, CLI 1.1.5 → 1.1.7, пауза/восстановление, удаление alpha.6. Упаковка alpha.10 и её live lifecycle имеют отдельный объём проверок: см. TEST-REPORT. Полная защита от DNS/IPv6/ускоренных утечек, сбои питания/USB и другие модели не подтверждены. Минимальная поддерживаемая прошивка этой поставки — 3004.388.12; самая ранняя совместимая версия ещё не определена.
