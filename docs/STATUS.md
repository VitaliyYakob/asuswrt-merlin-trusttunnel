# Состояние 0.2.1-alpha.1

Цель: ASUS RT-AX86U, Entware установлен (подтверждено пользователем). Версия Merlin и реальная структура guest bridge пока неизвестны. Роутер из этой сессии не подключался.

## Готово для локального тестирования

Нативная страница, ручной ввод и парсер tt://, приватный JSON export, SSID-инвентаризация без редактирования bridge, DNS только из подключения и политика schema3 нескольких bridge (основная + три гостевые, все/выбранные), старый schema1 import, TOML generator, контроллер и mock network executor. Собственные firewall/PBR правила, DNS, ограничение IPv6, pause/disable. Backups конфигурации и файлов установки. Git и исходный Template сохранены.

## Известное ограничение формы подключения

Прямое сохранение пароля из браузера на роутер не реализовано. Поддержан путь форма → скачанный JSON → SCP/SFTP → SSH import. Для browser-only apply нужен отдельно проверенный приватный транспорт, совместимый с конкретным httpd Merlin. Это самостоятельный этап, не скрытая готовая функция.

## Перед испытанием на роутере

Определить firmware/kernel и реальные bridge/subnets, проверить полный ip/iptables/Entware, официальный binary v1.1.5 aarch64, проверить HND acceleration, пройти docs/HARDWARE-TESTS.md. До этого статус — лабораторная alpha, не release для защиты рабочего трафика.

## Последующее расширение

Транзакционное изменение активной политики, приватный browser apply, достоверная проверка соединения, IPv6 routing, local-network exclusions, несколько профилей, GeoIP/domains. Наличие интерфейса или PID не заменяет handshake/проверку внешнего ресурса.
