# 0.3.1-alpha.5 — 2026-09-20

- Исправлены предпосылки первого запуска: штатный TUN-модуль загружается при необходимости; отсутствие сохранённой политики выявляется до сетевых изменений.
- На HND читается реальное состояние Flow Cache и hardware acceleration через fc status. Старый ctf_disable больше не считается доказательством отключённого HND. Глобальное отключение ускорения не требуется: выбранные IPv4-потоки и IPv6 выбранных bridge исключаются через SKIPLOG, существующий flow cache очищается только для этих bridge и их участников. Отсутствие механизмов или ошибка выборочной очистки блокирует запуск; установка не меняет ускорение.
- Панель и диагностика показывают причины отказа запуска вместо общего action_failed: несохранённое подключение/сети, TUN, DNS, изменившаяся сеть, ускорение, зависимости. В статус передаются только фиксированные коды, без фрагментов конфигурации или журналов.

- Исправлена неоднозначность jq-выражений проверки CIDR, приводившая к отказу сохранения политики на Entware jq 1.8.1. Добавлены переносимые проверки для host/router.

# 0.3.1-alpha.4 — 2026-09-20

- Исключения сохранённого подключения загружаются в WebUI и сохраняются отдельной кнопкой без пароля/ссылки. Частичный запрос допускает только список исключений; сервер объединяет его с приватным endpoint под блокировкой, проверяет ревизию и полную схему, сохраняет резерв. Активный VPN использует существующий пробный transaction apply.
- Панель явно сообщает о сохранённом подключении; несохранённые исключения не затираются обновлением статуса. При черновике нового подключения отдельное сохранение исключений заблокировано.
- Служебные Wi-Fi BSS за пределами трёх гостевых слотов исключены по правилу штатного Merlin 388 state.js (исключение BRT-AC828). Все пользовательские SSID общей подсети видны в заголовке. Ссылка DHCP на отсутствующий bridge выводит предупреждение, а не создаёт фиктивную сеть.

# 0.3.1-alpha.2 — 2026-09-20

- Исправлена обнаруженная на RT-AX86U / Merlin 388.12_2 несовместимость: проверка команд использует `type`, поскольку firmware BusyBox ash не содержит builtin `command`.
- Установщик до записи файлов проверяет дополнительные зависимости: mktemp, base64, od, stat и OpenSSL. Добавлены регрессии импорта и статуса без `command`.
- Единый `tools/setup-router.sh` устанавливает недостающие Entware-утилиты и закреплённый официальный клиент 1.1.5. SHA-256 проверяется до распаковки архива и установки binary; hash binary закреплён после настоящей проверки upstream-подписи.
- Проверяется поддержка регулярных выражений jq: минимальный Entware jq непригоден, требуется jq-full. Установка не включает VPN, не меняет ускорение и не создаёт сетевые правила.
- Штатные jquery/httpApi загружаются до state.js, как на нативной странице VPN Merlin; исправлена ошибка `$ is not defined` настоящего WebUI.
- Исправлено обрезание шифрованной передачи штатным httpd 388.12_2: учитывается notify_cmd[128], а не только rc_service[256]. RSA-блок передаётся шестью частями, команды не длиннее 127 символов. Срок передачи увеличен до 2 часов для максимальных 64 КиБ; успешное завершение/отмена сразу удаляет временный ключ.
- Начата аппаратная проверка установки без включения VPN; её фактические результаты и ограничения записаны в TEST-REPORT.

# 0.3.0-alpha.1 — 2026-09-20

- Четыре вкладки Merlin: обзор, подключение, сети и диагностика; импорт JSON/tt:// из файла, несохранённые изменения, клавиатурная навигация, журнал операций.
- Экспериментальное приватное сохранение через HTTPS/Web Crypto → RSA-OAEP SHA-256 → ограниченные service-event команды → OpenSSL. Шифртекст вместо пароля в штатной форме, подтверждения частей, временные ключи и очистка. Новый UI не записывает amng_custom.
- ID операций, защита от повторного выполнения в пределах runtime-истории и ревизии против конфликтующих сохранений. Результат не определяется фиксированным таймером.
- Транзакционное изменение активного endpoint/policy: резерв, журнал, блокировки объединения старых/новых сетей, пробное применение, подтверждение за 180 секунд и восстановление по cron/boot. При ошибке восстановления блокировки сохраняются.
- Policy schema4: идентификатор состава сети, выбор DHCP-устройств по /32 и локальные исключения с сохранением фильтрации Merlin. Bridge недоступен для редактирования; отдельный DNS не появился.
- Повторные попытки запуска с интервалом 60–900 секунд; восстановление guards не пропускается при ожидании. Диагностика совместимости без выгрузки секретов и журнала клиента.
- Локальная проверка подписи клиента по закреплённому ключу upstream; резерв предыдущего бинарника и блокировка контроллера при замене. Автоматической загрузки/запуска клиента нет.
- Расширены локальные регрессии и определения CI (закреплённый checkout, ShellCheck, браузер). Все аппаратные тесты, настоящая подпись релиза и удалённый CI остаются NOT RUN.

# 0.2.1-alpha.1 — 2026-09-14

- Сети отображаются по реальным SSID, найденным через состав bridge и wl-интерфейсы Merlin. Несколько SSID одной сети выбираются вместе; bridge отсутствует среди редактируемых полей.
- Удалены ручное добавление сетей и подставные br0–br3 при недоступной инвентаризации.
- Удалён отдельный DNS маршрутизации. Policy schema3 не содержит DNS; импорт legacy policy1/2 сохраняет резерв и переводит политику в schema3.
- DNS из tt:// сохраняется без подстановки, показывается только для чтения. При ручной подготовке DNS задаётся в самой конфигурации подключения без значения по умолчанию.
- Пустой DNS не заменяется внешним сервером; запуск с такой конфигурацией отклоняется. DNS клиентов передаётся внутреннему обработчику TrustTunnel с настроенным dns_upstreams.
- Добавлены регрессии SSID mapping, DNS migration, неизменяемого bridge, подмены DOM и отсутствующих сетей.

## 0.1.0-alpha.1

Initial independently implemented native Merlin addon, shell controller, policy/endpoint validation,
TOML generator, declarative routing plans, ownership-aware cleanup, hooks/menu integration,
private credential import, frontend, offline preview and host-side tests.

Fixed during initial local verification: JSON-plan syntax, validation failure propagation through
pipelines, canonical executable matching for symlinked /opt, restoration of a lost tunnel route while
the client remains alive, and atomic repositioning of guard jumps before subsequently inserted rules.

No hardware, upstream-client execution or end-to-end VPN tests have been performed.
