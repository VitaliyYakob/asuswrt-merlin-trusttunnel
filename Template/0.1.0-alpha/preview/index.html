Маршрутизация

IPv4 выбранных адресов направляется в TrustTunnel. Укажите реальный bridge своей LAN или гостевой сети; имя нельзя определить без проверки роутера.

Изменение политики доступно только после явного отключения аддона. Доменные списки, GeoIP и полноценная IPv6-маршрутизация ещё не реализованы.

Подключение к серверу

В этой версии учётные данные импортируются по SSH из приватного JSON-файла. Пароль не передаётся через custom_settings и не публикуется в статусе.

trusttunnel.sh import-endpoint /tmp/endpoint.json

Формат: examples/endpoint.example.json. Журнал клиента доступен только локально: /tmp/trusttunnel/client.log.
